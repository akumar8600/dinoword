# 🦖 DinoWord — AI-Powered Kids Vocabulary App

> *"Learn Words, Roar with Knowledge!"*

DinoWord is a **Progressive Web App (PWA)** that helps children aged 6–12 build their vocabulary through AI-generated word cards, playful quizzes, and a lovable dinosaur companion. Built with vanilla HTML/CSS/JS and powered by the **Claude claude-sonnet-4-20250514 API**, it installs directly on Android and iOS home screens — no app store required.

## ✨ Features

### 🤖 AI-Powered Word Cards (Learn Mode)
Every word is dynamically generated by Claude AI — no static dictionary. Each card includes:

| Field | Example (word: *elephant*) |
|-------|---------------------------|
| **Word** | ELEPHANT |
| **Pronunciation** | *EL-uh-funt* |
| **Meaning** | A very large animal with a long nose called a trunk |
| **Example Sentence** | *"The elephant sprayed water on itself to cool down."* |
| **Memory Trick** | *"Elephants are ELE-gant giants — the trunk is like a built-in water pistol!"* |
| **Fun Fact** | *"Elephants can remember places and friends for over 50 years!"* |
| **Emoji** | 🐘 |

**Example API prompt used internally:**
```
Word: elephant
Category: Animals
Difficulty: Easy
→ Returns: full JSON word card via claude-sonnet-4-20250514
```

### 🎮 AI-Powered Quiz Mode
Claude generates a fresh multiple-choice question every round — no repeated questions from a static bank.

```
┌─────────────────────────────────┐
│  What does this word mean?      │
│                                 │
│       G A L A X Y               │  ← Big styled word
│   💡 Hint: "Think of stars"    │  ← Easy/Medium only
│                                 │
│  Choose the correct meaning:    │
│                                 │
│  🅰️  A huge system of stars     │  ← Correct ✅
│  🅱️  A type of ice cream flavor │  ← Wrong ❌
│  🇨  A fast-moving storm        │
│  🇩  The surface of the moon    │
└─────────────────────────────────┘
```

After answering:
- ✅ **Correct** → Dino bounces with gold glow + example sentence revealed
- ❌ **Wrong** → Dino shakes + correct answer highlighted in green

### 🏆 Gamification & Progression

#### Score System
| Difficulty | Points per correct answer |
|------------|--------------------------|
| 🥚 Easy   | +10 points               |
| 🐣 Medium  | +20 points               |

Locked badges appear greyed out with a grayscale filter. Earned badges glow with a pulsing gold animation.

### 📲 Progressive Web App (PWA)
DinoWord is a fully installable PWA with:

- **`manifest.json`** — app name, icons, theme colour (`#FF6A00`), standalone display mode
- **`sw.js`** — Service Worker with cache-first strategy for app assets; always fetches live from Anthropic API
- **Offline support** — app shell loads offline; AI calls require internet
- **Home screen install** — Chrome on Android shows "Add to Home Screen" banner automatically
- **Fullscreen launch** — no browser bar when opened from home screen
- **localStorage persistence** — score, streak, and win count survive app restarts

## 🚀 Quick Start


## 🔑 API Key Setup

DinoWord calls the **Anthropic Claude API** for word data and quiz generation.

### When running inside Claude.ai Artifacts
The API key is handled automatically — no setup needed.

### When self-hosting (Netlify / GitHub Pages / local)
You need a free Anthropic API key:

1. Sign up at [console.anthropic.com](https://console.anthropic.com)
2. Create an API key
3. In `index.html`, find the two `fetch("https://api.anthropic.com/v1/messages", ...)` calls
4. Add the header to each:

```javascript
// In fetchWordData() and fetchQuizData():
headers: {
  "Content-Type": "application/json",
  "x-api-key": "sk-ant-YOUR_KEY_HERE",          // ← add this
  "anthropic-version": "2023-06-01",             // ← add this
  "anthropic-dangerous-direct-browser-iab": "true"  // ← required for browser calls
}
```

> 💡 For production, move API calls to a backend/serverless function to keep your key secret.

### State Management
All UI state lives in a single `state` object (no framework needed). Every action calls `render()` which replaces the DOM via `replaceChildren()` — a simple, fast virtual-DOM-free approach.

```javascript
// Example state shape
{
  screen: "home",        // "home" | "learn" | "quiz"
  cat: CATS[0],          // selected category object
  diff: DIFFS[0],        // selected difficulty object
  score: 60,             // persisted in localStorage
  streak: 4,             // persisted in localStorage
  wins: 7,               // persisted in localStorage
  mood: "idle",          // drives dino animation class
  wordData: { ... },     // current AI word card
  quizData: { ... },     // current AI quiz question
  quizOptions: [...],    // shuffled answer options
  feedback: "correct",   // null | "correct" | "wrong"
}
```

## 📡 API Integration Details

### Word Card Request
```javascript
// System prompt (simplified)
"You are DinoWord, a cheerful vocabulary teacher for kids.
Return ONLY valid JSON:
{ word, pronunciation, meaning, fun_fact,
  example_sentence, memory_trick, emoji }"

// User message
"Word: volcano. Category: Nature. Difficulty: Medium"
```

### Quiz Generation Request
```javascript
// System prompt (simplified)
"You are DinoWord quiz master for kids.
Return ONLY valid JSON:
{ word, correct_meaning, wrong_options: [3 items],
  example_sentence, hint }"

// User message
"Word: telescope. Category: Space. Make it fun and kid-appropriate!"
```

### Response Handling
```javascript
const data = await response.json();
const text = data.content
  .map(c => c.text || "")
  .join("")
  .replace(/```json|```/g, "")  // strip any markdown fences
  .trim();
const parsed = JSON.parse(text);
```

```javascript

  label: "Animals",
  emoji: "🦁",
  color: "#FF9500",
  bg: "#FFF3E0",
  words: [
    "elephant", "giraffe", "dolphin", /* add more here */
    "orangutan", "narwhal", "axolotl"
  ]

```

### Adding a New Category
```javascript
{
  id: "science",
  label: "Science",
  emoji: "🔬",
  color: "#E91E63",
  bg: "#FCE4EC",
  words: ["photosynthesis","evaporation","magnetism","hibernation",...]
```

### Changing Point Values
```javascript
// In handleAnswer():
state.score += (
  state.diff.id === "hard"   ? 30 :   // change here
  state.diff.id === "medium" ? 20 :   // change here
  10                                   // Easy — change here
);
```

### Updating the Dino Mascot
Replace the image source in `index.html`:
```javascript
// Replace this line near the top of the <script>:
const DINO_SRC = "data:image/jpeg;base64,...";

// With a URL:
const DINO_SRC = "https://your-cdn.com/your-mascot.png";
// Or a new base64 string for a different embedded image
```

### Changing Badge Thresholds
```javascript
const BADGES = [
```

## 🐛 Known Limitations

| Limitation | Workaround |
|------------|------------|
| API calls require internet | App shell loads offline; words cached after first fetch |
| API key exposed in client-side JS | Move to a Netlify/Vercel serverless function for production |
| Service Worker caches on HTTPS only | Use `localhost` or a hosted URL during development |
| No user accounts / cloud sync | Scores stored in `localStorage` — device-specific |
| iOS PWA loses state on app close | `localStorage` persists; in-session state resets |
